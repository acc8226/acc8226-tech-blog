## 前言

价值导向：功能 大于 颜值，同时要考虑价格因素
是否静音：在我的印象中普通静音鼠标的反馈感不好。
有线无线：我更倾向于有线，不用换电池且延迟较低且便宜
大手小手：区分小手和大手鼠标（小手 中指到第一横纹处 < 17.5 cm，小于 19 则是中手，大于则是大手）
品牌选择：罗技 g102 或者 老品牌双飞燕（即使没有鼠标侧边按键，用鼠标手势也能代替不少工作）
侧边按键：除非手感好，否则还不如鼠标手势好用

## 软件篇

### 侧键增强 for linux

在 Kubuntu（KDE/X11）下，最稳妥的做法是用 **xbindkeys + xdotool**：把鼠标侧键（通常是 button 8 / button 9）模拟成键盘组合键。

#### 1. 安装工具

```bash
sudo apt update
sudo apt install xbindkeys xdotool
```

#### 2. 确认侧键编号

```bash
xev | grep button
```

把鼠标移到弹出的小窗口里，按“后退”“前进”两个侧键：

- 常见：后退 = `button 8`，前进 = `button 9`
- 也可能是 6/7，以你终端输出为准

#### 3. 写配置 `~/.xbindkeysrc`

如果文件不存在先生成：

```bash
xbindkeys --defaults > ~/.xbindkeysrc
```

然后追加：

```conf
# 侧键1（后退键）→ Ctrl+W 关闭标签页
"xdotool key ctrl+w"
b:8

# 侧键2（前进键）→ Ctrl+Shift+Tab 上一个标签页
"xdotool key ctrl+shift+Tab"
b:9
```

> 注意：`Tab` 首字母大写；如果你想“前进键 = 下一个标签页”，用 `ctrl+Tab`。

#### 4. 生效

```bash
killall xbindkeys
xbindkeys
```

测试：在 Firefox / Chrome / VS Code 里按侧键，应该分别关闭标签、切到上一个标签。

#### 5. 开机自启（KDE）

系统设置 → **开机和关机 → 自动启动** → 添加程序：

```
xbindkeys
```

或者把下面这行放进 `~/.xprofile`：

```bash
xbindkeys
```

#### ⚠️ Wayland 情况

如果你登录的是 **Plasma Wayland 会话**，xbindkeys/xdotool 可能不生效。

解决思路：

- 登录时选 **Plasma (X11)**
- 或用 `input-remapper` / `keyd` / `python-evdev` 在更底层重映射
