对于使用 systemd 的系统(Ubuntu 16.04+、Debian 8+、CentOS 7+)，可以创建 /etc/docker/daemon.json 文件，并写入如下内容（如果文件不存在请新建该文件）：

```sh
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://docker.m.daocloud.io",
    "https://docker.1ms.run",
    "https://docker.xuanyuan.me"
  ]
}
EOF
```

<!-- more -->
最后别忘记重新启动 docker：

```sh
sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 加速服务示例

我一般在 [毫秒镜像](https://1ms.run/) 去查询对应版本，并进行镜像拉取。

拉取 nginx
docker pull docker.1ms.run/library/nginx:stable-alpine3.24
测试是否可用
sudo docker run --rm -p 80:80 docker.1ms.run/library/nginx:stable-alpine3.24
